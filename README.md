# ZT Local Bridge

### Версия 0.5

Добавлены именованные профили и поддержка управляемых
IPv4-маршрутов ZeroTier через шлюзы к удалённым LAN. Существующие настройки
мигрируют в профиль «Основной». Поддержка не зависит от марки роутера;
выбранный маршрут виден в журнале. Для этой версии подсети ZeroTier и LAN
не должны перекрываться.

Android-клиент, который пробрасывает локальный TCP-порт через ZeroTier **без создания системного VPN**. Можно использовать одновременно с v2rayNG и другими VPN-клиентами.

```text
Приложения → v2rayNG (VPN) → 127.0.0.1:15000
                              ↓
                       ZT Local Bridge
                              ↓
                     VPS в сети ZeroTier
```

**[Скачать APK 0.5](https://github.com/kyurenbog/zt-local-bridge/raw/refs/heads/main/downloads/ZT-Local-Bridge-0.5.apk)** · [Инструкция](ИНСТРУКЦИЯ.md)

## Возможности

- Собственный узел ZeroTier без `VpnService` и без root.
- Настройка Network ID, IPv4-адреса VPS, локального и удалённого портов.
- Именованные профили сетей и серверов с переносом старых настроек.
- Управляемые IPv4-маршруты ZeroTier через шлюзы к удалённым подсетям.
- Лимит TCP-соединений 16–512, по умолчанию 256.
- Очистка зависших и полузакрытых соединений без перезапуска.
- Счётчики трафика и соединений.
- Раздельная индикация готовности сети, поступления данных от VPS и задержки обновления статуса.
- Отдельный журнал с фильтрами, выделением текста, копированием и отправкой.
- Ручная прокрутка приостанавливает слежение: новые события не сбрасывают позицию.
- Тёмный интерфейс и контрастная адаптивная иконка.

## Быстрый старт

1. Установите APK. Требуется Android 8+ и ARM64. Прототип проверен на Android 16.
2. Отключите обычный ZeroTier, если он работает как системный VPN.
3. Исключите **ZT Local Bridge** (`org.ztbridge.android`) из VPN в настройках v2rayNG.
4. Введите Network ID своей сети, адрес VPS **внутри ZeroTier**, порт сервиса и локальный порт.
5. Нажмите **Подключить**. При первом запуске разрешите показанный Node ID в панели своей сети.
6. В копии нужного профиля v2rayNG задайте адрес `127.0.0.1` и выбранный локальный порт.
7. Сохраните остальные настройки профиля, включая SNI, ключи и параметры REALITY, затем включите v2rayNG.

На VPS должен работать нужный TCP-сервис, доступный через ZeroTier. Приложение не превращает любой узел сети в интернет-шлюз автоматически.

## Ограничения

Это экспериментальный **TCP-проброс на один адрес и порт**, не SOCKS-прокси и не полноценный системный адаптер ZeroTier. UDP и произвольные маршруты не поддерживаются. Проверяйте совместимость транспорта своего профиля отдельно.

Событие ZeroTier `offline` не является самостоятельной проверкой доступности VPS. Зелёный статус передачи означает, что от VPS поступали данные за последние 10 секунд; он не проверяет открытие сайтов или успешную авторизацию REALITY.

Полузакрытый поток завершается после 15 секунд без передачи данных, полностью неактивный — после 120 секунд. Активная передача обновляет таймер. Пул v2rayNG может удерживать соединения некоторое время после завершения запроса.

## Сборка

```bash
git clone --recurse-submodules https://github.com/kyurenbog/zt-local-bridge.git
cd zt-local-bridge
```

Нужны JDK 17, Android SDK 36, Build Tools 36.0.0, NDK 28.2.13676358 и CMake 3.22.1. Задайте `ANDROID_HOME` или `sdk.dir` в локальном `local.properties`.

```bash
sdkmanager "platforms;android-36" "build-tools;36.0.0" "ndk;28.2.13676358" "cmake;3.22.1"
./gradlew :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

На Windows используйте `gradlew.bat`. Для Windows рекомендуется путь к проекту без кириллицы и других не-ASCII символов. APK появляется в `app/build/outputs/apk/debug/`.

При обновлении клона:

```bash
git submodule update --init --recursive
```

Сборка из исходников создаёт локальный debug-ключ. Он может отличаться от ключа опубликованного APK, поэтому Android может отказать в установке такой сборки поверх готовой версии. Не публикуйте приватные ключи подписи и файлы identity ZeroTier.

## Технологии и зависимости

- Android Java + небольшой JNI-адаптер.
- [ZeroTier Sockets / libzt](https://github.com/zerotier/libzt), закреплённый submodule: `a707ea6ae0910efdc1125d04758c411e2e9ea4f9`.
- Ядро ZeroTier и его зависимости используются без изменений. Лицензии и уведомления зависимостей включаются в assets APK (`upstream-notices`). См. [NOTICE.md](NOTICE.md).

Это независимый проект, не официальный Android-клиент ZeroTier. Лицензия собственного кода проекта пока не выбрана; лицензии зависимостей действуют отдельно.
