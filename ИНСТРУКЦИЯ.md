# Настройка ZT Local Bridge

## Профили и маршруты — версия 0.5

Настройки предыдущей версии автоматически становятся профилем **Основной**.
В разделе **Подключение** можно выбрать профиль, создать новый, изменить его
имя или удалить ненужный. У каждого профиля своя сеть, адрес сервера,
локальный/удалённый порт и лимит соединений. Незавершённые правки сохраняются
при переключении. Чтобы сменить профиль, сначала остановите мост.

Ключ устройства общий для профилей: при переходе в новую закрытую сеть
потребуется авторизовать тот же Node ID в её панели управления.

IPv4-маршруты к удалённым подсетям берутся из конфигурации выбранной сети
ZeroTier. Шлюзом может быть любой поддерживающий пересылку роутер или сервер;
приложение не привязано к OPNsense. Адрес сервера может быть как ZeroTier-IP,
так и IP машины за таким шлюзом. Выбранный маршрут отображается в статусе
и журнале. Если маршрут изменён или удалён в контроллере, таблица обновляется.

Маршрут должен быть задан в ZeroTier, а не только вручную в ОС другого ПК.
Подсети ZeroTier и удалённой LAN не должны перекрываться. Для удалённой LAN
также нужен обратный маршрут либо NAT на шлюзе. IPv6-маршруты в этой версии
не реализованы; маршруты по умолчанию и глобальные маршруты не включаются
вопреки настройкам allowDefault/allowGlobal сети встроенного клиента.

## Подключение

1. Установите APK из папки `downloads` этого репозитория. Для обновления используйте установку поверх приложения, сохраняя данные: так остаётся прежний ключ ZeroTier и Node ID.
2. В v2rayNG исключите **ZT Local Bridge** из VPN. Обычный клиент ZeroTier должен быть отключён.
3. Введите **Network ID** — 16 шестнадцатеричных символов.
4. Введите **IP VPS в сети ZeroTier**, порт нужного сервиса и локальный порт, например `15000`.
5. Сохраните настройки и нажмите **Подключить**.
6. Разрешите новый Node ID в панели сети ZeroTier. Он отличается от Node ID обычного клиента, установленного на том же телефоне.
7. В копии профиля v2rayNG задайте адрес `127.0.0.1`, порт `15000` либо своё значение. Параметры TLS/REALITY и SNI сохраните: SNI нельзя заменять локальным IP.
8. Включите этот профиль v2rayNG.

Настройки сети и VPS не встроены в публичный APK. Каждый пользователь вводит свои. Если Android производителя завершает приложение в фоне, разрешите ему фоновую работу в настройках батареи.

## Лимит соединений

Диапазон: 16–512, по умолчанию 256. Для изменения остановите мост, сохраните значение и подключитесь снова. Больший лимит повышает расход памяти.

Счётчик показывает занятые места и максимум, например `37 / 256`. Он не обязан падать сразу после Speedtest: VPN-клиент может сохранять соединения для повторного использования.

Полузакрытые потоки очищаются после 15 секунд без передачи данных, остальные неактивные потоки — через 120 секунд. Увеличение лимита не заменяет устранение реальной сетевой проблемы.

## Статусы

- **Передача данных** — за последние 10 секунд от VPS поступали данные.
- **Мост готов** — локальный порт открыт и сеть ZeroTier готова; это не тест доступа в интернет.
- **Мост запущен / связь не подтверждена** — служба работает, но нет свежего подтверждения передачи, а ZeroTier сообщает offline или неготовность сети.
- **Статус задерживается** — интерфейс не получил свежие показатели. Это само по себе не доказывает остановку службы.

## Журнал

Кнопка **Журнал** открывает отдельный экран. Есть основные события, только ошибки и подробный режим TCP.

При ручной прокрутке слежение отключается. Пока вы читаете старые строки, текст не заменяется новыми записями. Нажмите **Новые записи ↓** или включите **Следить за новыми записями**, чтобы продолжить обновление.

Можно выделять текст, копировать полный журнал, делиться им и очищать записи. Последние 200 записей сохраняются между запусками. Перед публичной отправкой журнала проверьте его: в нём могут быть Network ID, Node ID и адрес вашего VPS.
